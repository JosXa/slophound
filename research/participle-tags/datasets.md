# Recent attributed prose sources (research notes)

Checked 5 October 2026. Dates below distinguish repository creation from collection. These sources can supply candidate constructions. They do not establish a reliable human baseline or prove that any construction needs a rule. Save a dataset revision and row identifier before extracting examples.

## Best sources to sample

1. **[Trace Commons agent traces](https://huggingface.co/datasets/trace-commons/agent-traces)**: HF repository created **11 June 2026**; sampled sessions have `sent_at` dates in June 2026. Public, no access agreement. Donated agent sessions contain `harness`, `session_id`, `prompt`, role-separated `messages`, `tools`, `trace`, `metadata`, and `sent_at`. The metadata sometimes identifies a precise model, but `harness=claude_code` alone does not. [Directly inspected rows 0–9](https://datasets-server.huggingface.co/rows?dataset=trace-commons%2Fagent-traces&config=default&split=train&offset=0&length=10): row 9, session `4222016d-1932-4abb-94b3-463203bd8876`, labels `metadata.model=claude-sonnet-4-6` and writes `d:\DMLS\README.md` via an assistant `Write` call. The generated introduction reads "A minimal life simulation engine. Maximal engineering underneath." Row 0 writes `PROJECT.md` milestones. Row 1 writes an HTML interface with "Initializing system architecture..." and HTML comments such as `<!-- Boot Screen -->`. Row 8 writes TypeScript with short `// Auth` and `// Jobs` comments. These are observed artifacts, rather than merely promised content. Extract `function.arguments.content` from assistant `Write` calls. Exclude `Read` results, user-supplied Markdown, and later repeats of the same file. The [publisher's collection and license notes](https://huggingface.co/datasets/trace-commons/agent-traces) describe opt-in donation, local scrubbing, contributor certification, and maintainer review. CC BY 4.0 covers the compilation, while individual traces and repository files can have separate terms. The collection is self-selected, and the publisher does not certify every underlying right.

2. **[Nebius OpenHands trajectories](https://huggingface.co/datasets/nebius/SWE-rebench-openhands-trajectories)**: HF repository created **22 September 2025**; the card gives no precise execution dates for every run. Public, CC BY 4.0. Publisher identifies one generator, **`Qwen/Qwen3-Coder-480B-A35B-Instruct`**, under OpenHands v0.54.0 across 67,074 runs on real GitHub issues. Fields include `trajectory_id`, `instance_id`, `repo`, role-separated `trajectory`, `model_patch`, `exit_status`, and `resolved`. [Row 0](https://datasets-server.huggingface.co/rows?dataset=nebius%2FSWE-rebench-openhands-trajectories&config=default&split=train&offset=0&length=1), instance `PlasmaFAIR__sdf-xarray-24`, has assistant explanation "I'll help you implement the necessary changes to handle forward slashes in variable names when writing to NetCDF." Its patch adds a test file headed "Comprehensive test of the forward slash fix" and includes comments. For prose comments, select additions in `model_patch`; inspect `assistant` turns separately. System instructions, user issue text, and tool observations are different sources. The source task benchmark is not the generator.

3. **[WildChat-4.8M](https://huggingface.co/datasets/allenai/WildChat-4.8M)**: HF repository created **8 August 2025**; the [card's 11 August 2025 update](https://huggingface.co/datasets/allenai/WildChat-4.8M/raw/main/README.md) states coverage through **31 July 2025**. Public ODC-BY release has **3,199,860 filtered conversations**, although the full source has roughly 4.8 million. Per-row `model`, `conversation_hash`, `timestamp`, and role-separated `conversation` expose ChatGPT replies. Turn identifiers are safer keys than the hash. Card model families include `gpt-4o`, `gpt-4.1-mini`, `gpt-3.5-turbo`, `gpt-4`, `gpt-4-turbo`, `o1-preview`, and `o1-mini`. Preserve the actual row's snapshot: [the first 16 directly returned rows](https://datasets-server.huggingface.co/first-rows?dataset=allenai%2FWildChat-4.8M&config=default&split=train) are dated April 2023 and include `gpt-4-0314` and `gpt-3.5-turbo-0301`. One user asks for website policies, but the assistant declines. The `/first-rows` endpoint worked. The `/rows` endpoint returned HTTP 500 during this inspection. For current output, sample later dated shards or search [WildVis](https://wildvisualizer.com/) and verify the resulting row against the release.

4. **[LLM-jp Chatbot Arena conversations](https://huggingface.co/datasets/llm-jp/llm-jp-chatbot-arena-conversations)**: HF repository created **10 April 2025**; the card dates collection to **January–February 2025**. Public JSONL of 990 paired conversations, chiefly Japanese. The [first raw record](https://huggingface.co/datasets/llm-jp/llm-jp-chatbot-arena-conversations/resolve/main/conversations.jsonl) has `model_a=Qwen2.5-72B-Instruct`, `model_b=Tanuki-8B-dpo-v1.0`, `language=ja`, `tstamp=1738146483.0545`, two role-labeled conversations, and `winner`; an assistant explains why soy sauce is a condiment. Its model labels and parallel answers support comparison, but the language and mostly short replies make it less suitable for English documentation. The card grants CC BY 4.0 for user prompts while model answers retain their respective model licenses; HF's `cc` tag is not a complete license. The raw JSONL streamed successfully although the dataset viewer returned HTTP 500.

## Lower priority and gaps

- [WebGen-Agent SFT traces](https://huggingface.co/datasets/luzimu/webgen-agent_train_sft) were published in an HF repository created **31 August 2025** (MIT). [Row 0](https://datasets-server.huggingface.co/rows?dataset=luzimu%2Fwebgen-agent_train_sft&config=default&split=train&offset=0&length=1) has `messages`, `id=train_000042`, `step=step10.json`; the assistant emits a `<boltArtifact>` with `src/App.jsx` and prose about improving feedback for an SMS-to-XMPP website. The card describes several model choices and released checkpoints but does **not** assign a verified exact generator to this row. It can supply UI prose, but model-attributed comparisons need stronger attribution.
- [WebGen-Bench](https://huggingface.co/datasets/luzimu/WebGen-Bench) (HF repository created **1 May 2025**) and [MM-WebGen-Bench](https://huggingface.co/datasets/microsoft/MM-WebGen-Bench) (created **16 April 2026**) release website **instructions**, rather than corresponding generated pages in their dataset rows. Their MIT cards do not establish authored website-copy samples. [SWE-rebench-V2](https://huggingface.co/datasets/nebius/SWE-rebench-V2) (created **4 February 2026**) has real issue/PR tasks and `pr_description`, `problem_statement`, and gold `patch`; `meta.llm_metadata` describes annotations, not an identified author of the gold patch. The compilation declares CC BY 4.0 with underlying repository terms.
- [ShareChat](https://huggingface.co/datasets/tucnguyen/ShareChat) (created **15 January 2026**) is gated with automatic acceptance. Its raw card returned HTTP 401 before agreement. No per-row exact model identity was verified. No official newer English LMArena conversation-text release was established by this search. A leaderboard or vote collection need not expose assistant prose.

For a construction search, start with Trace Commons `Write` artifacts in `.md`, `.html`, `.tsx`, and `.jsx`, then Nebius patch additions and WildChat assistant turns. Keep exact model strings, role, date, file identifier, dataset revision, and extraction path alongside each match. No source here reliably labels *unaided* human prose. Compare candidate patterns against independently dated reference documentation and read every apparent match in context.
